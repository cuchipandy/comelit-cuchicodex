# Repository context

This fork is maintained at https://github.com/cuchipandy/comelit-cuchicodex.
See [README.md](README.md) for installation and
[docs/DEVELOPMENT.md](docs/DEVELOPMENT.md) for layout, branches and checks.

The historical upstream audit/backlog in `memory/` is retained for reference;
its dates and coverage figures must not be presented as current verification.
Old upstream host paths, deployment addresses and the `dev` branch workflow
are not applicable to this fork.

Keep secrets and packet captures local. Protocol/media changes require targeted
regressions and honest reporting of hardware validation. Repository maintenance
does not authorize deployment to Home Assistant or operation of the door.
